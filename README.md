# Zomato Delivery Performance Analysis | SWYNEX Technologies Pvt. Ltd.

## Project Overview

This project was completed as part of a Data Analytics project assignment from **SWYNEX Technologies Pvt. Ltd.**

The objective was to analyze Zomato delivery data, explore factors associated with delivery time, and present the findings through an interactive Power BI dashboard.

The project covers the end-to-end analytics workflow: data cleaning, exploratory data analysis (EDA), data visualization, and insight reporting.

## Project Objectives

* Prepare and clean the dataset for analysis.
* Explore delivery performance using Python.
* Analyze delivery time across traffic density, weather conditions, vehicle types, city categories, and festival status.
* Build an interactive Power BI dashboard.
* Summarize findings and provide practical recommendations.

## Dataset Summary

The prepared dataset contains **45,584 rows and 20 columns**. It includes delivery-related information such as order dates, delivery duration, traffic density, weather conditions, vehicle type, city category, and festival status.

## Key Findings

* The overall average delivery time was approximately **26.29 minutes**.
* Orders recorded under jam traffic averaged **31.18 minutes**, compared with **21.27 minutes** under low traffic.
* The average delivery time for sunny conditions was approximately **21.86 minutes**.
* Orders marked as festival-related had a higher average delivery time in this dataset than orders marked as non-festival-related.

These findings are descriptive patterns in the dataset and do not, by themselves, establish causation.

## Recommendations

* Monitor delivery performance during high-traffic periods.
* Examine staffing and delivery capacity during festival periods.
* Track delivery performance under different weather conditions.
* Improve data quality by validating unknown and inconsistent category values.
* Use the dashboard to compare delivery metrics interactively.

## Limitations

* Some records contain unknown category values.
* The dataset covers a limited period and may not represent year-round patterns.
* Differences between categories may be influenced by other factors, such as delivery distance and order mix.
* The analysis identifies associations rather than proving cause and effect.
